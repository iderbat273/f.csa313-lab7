## Туршилтын үр дүнгийн дүгнэлт

Хайгуулын тестийн үеэр туршилтын төлөвлөгөөнд заасан чиглэлүүдийн дагуу уншлагын жагсаалтын вэб интерфэйс болон API-г шалгасан. Вэб интерфэйсээр хүчинтэй ном нэмэх үйлдэл амжилттай ажилласан. Харин бүх талбарыг хоосон орхиж ном нэмэхэд систем шаардлагатай талбаруудыг шалгахгүйгээр хоосон бүртгэл үүсгэсэн. API нь мөн хоосон JSON объект хүлээн авч, HTTP 201 Created хариу буцаан, шаардлага хангаагүй ном үүсгэсэн. Ном устгасны дараа дэлгэц дээрх “Ном нэмэгдлээ” гэсэн мэдэгдэл хэвээр үлдэж, хэрэглэгчийг төөрөгдүүлэх боломжтой байв. API-ийн шалгалтаар номын жагсаалтаас буцаасан бүртгэлийн тоо болон статистикийн `total` утга зөрсөн тохиолдол ажиглагдсан. API хүсэлтүүдийг `curl -i` командаар ажиллуулж, HTTP хариунуудыг нотлох баримт болгон хадгалсан. Эхний төлөв, хүчинтэй ном нэмэх, хоосон талбар илгээх болон ном устгасны дараах мэдэгдлийг харуулсан дэлгэцийн зургуудыг хадгалсан. `session-notes.md` файлд хийсэн үйлдэл, ажиглагдсан үр дүн болон цагийн тэмдэглэлүүдийг бүртгэсэн. Статистикийн тооны зөрүүг алдааны тайланд тусгасан бөгөөд эцсийн байдлаар баталгаажуулахын тулд серверийг анхны төлөвт оруулсны дараа дахин шалгах шаардлагатай.
